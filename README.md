## 📂 Como Atualizar Dados e Textos

Todos os dados da empresa, textos dos serviços e perguntas frequentes estão centralizados em um único arquivo:

👉 **`src/config/siteConfig.ts`**

Para alterar telefone, textos de serviços, adicionar bairros ou horários, basta editar esse arquivo. As propriedades opcionais que estiverem como `null` ou vazias não serão exibidas para o visitante (sem placeholders).
